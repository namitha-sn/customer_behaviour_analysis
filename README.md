# customer_behaviour_analysis

This project analyzes customer shopping behavior using SQL and interactive dashboards.
The goal is to extract meaningful business insights such as revenue contribution, customer segmentation, product performance, and subscription impact.

The workflow includes:

1.Loading dataset into MySQL
2.Performing data cleaning and transformation
3.Writing analytical SQL queries
4.Building an interactive Power BI dashboard
5.Presenting key business insights

->Dataset

The dataset contains customer transaction data with the following fields:
Customer ID
Age
Gender
Item Purchased
Category
Purchase Amount (USD)
Discount Applied
Subscription Status
Shipping Type
Previous Purchases
Review Rating
Age Group (Derived)

->Tools & Technologies

MySQL 8.0 – Database management and SQL analysis
Power BI Desktop – Interactive dashboard creation
VS Code – SQL scripting
MySQL Command Line / Workbench – Query execution
